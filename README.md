## ✨ Features

Dev-Tab is packed with tools designed to boost productivity, keep you informed, and provide a visually stunning experience every time you open a new tab.

- 🖥️ **Terminal Header & Command Palette**: Navigate quickly using keyboard shortcuts.
- 🎨 **Theme Switcher**: Multiple developer-focused themes (including *Tokyo Night*).
- 🧑‍💻 **Dev Feeds**: Stay updated with the latest tech news, filterable by language.
- ⏱️ **Focus Timer**: Built-in Pomodoro timer to maintain deep work.
- 📝 **Dev Notes / Scratchpad**: Instantly jot down ideas and code snippets.
- 📈 **GitHub Heatmap**: Display your real-time GitHub contribution graph.
- 🎧 **Lofi Player & Ambient Sounds**: Stay in the zone with built-in background audio.
- 🌐 **Server Monitor**: Keep an eye on your local or remote server statuses.
- 🪙 **Crypto & Stock Ticker**: Live market updates directly on your dashboard.
- 🔧 **Dev Utils Modal**: Quick access to common developer utilities.
- 🌧️ **Matrix Background**: Toggleable raining code aesthetic.
- ⚙️ **Highly Customizable**: Toggle any widget on or off via the Settings menu.

## 🚀 Installation

### Option 1: Load Unpacked (Development)

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/devtab.git
   cd devtab
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Build the extension:
   ```bash
   npm run build
   ```
4. Open your browser and navigate to the Extensions page (`chrome://extensions/` or `edge://extensions/`).
5. Enable **Developer Mode**.
6. Click **Load unpacked** and select the `dist` folder located in the project directory.

### Option 2: Pre-packaged ZIP

1. Download the latest `DevTab-Extension.zip` from the [Releases](#) page.
2. Extract the ZIP file.
3. Go to your browser's Extensions page, enable **Developer Mode**, and click **Load unpacked**.
4. Select the extracted folder.

## 💻 Development

Want to contribute or customize it for yourself?

Start the development server with Hot Module Replacement (HMR):
```bash
npm run dev
```

To build a production-ready package:
```bash
npm run build
```

To create a zipped extension package (`DevTab-Extension.zip`):
```bash
npm run pack
```
